# 就一件 · 部署说明

一次只做一件事。不显示清单，不显示还剩多少，不打卡，小搭子永远不会因为她没做而难过。

> 🌐 **线上地址**：<https://angel-ze.github.io/jiu-yi-jian/>
> 手机 Chrome 打开 → 右上角 ⋮ → 添加到主屏幕。

---

## 一、文件说明

| 文件 | 作用 | 能不能改 |
|---|---|---|
| `index.html` | **整个应用**。所有功能、样式、逻辑都在这一个文件里 | 主文件，改它就等于改应用 |
| `manifest.webmanifest` | 让手机认得它是个 App（名称、图标、全屏） | 改名字/主题色时改 |
| `sw.js` | Service Worker，负责离线可用 | 一般不用动 |
| `icon-192.png` / `icon-512.png` | 桌面图标（程序生成，不是图片素材） | 换图标时重新生成 |
| `tools/make-icons.js` | 图标生成脚本，纯 Node 无依赖 | 想换颜色就改这里再跑 |

**没有服务器、没有数据库、没有账号系统。** 数据全部存在她手机的浏览器本地（localStorage），不上传任何地方。

---

## 二、先在电脑上试

直接双击 `index.html` 就能用。

注意：`file://` 打开时 Service Worker 不会注册，所以没有离线缓存和"添加到主屏"的完整形态——**功能全部正常**，只是少那层。要完整体验必须先部署。

---

## 三、部署（拿到一个 https 网址）

### 方案 A：GitHub Pages（免费，推荐）

1. 注册 [github.com](https://github.com)
2. 右上角 **+ → New repository**，名字填 `jiu-yi-jian`，选 **Public**，创建
3. 进入仓库 → **Add file → Upload files**，把这 5 个文件拖进去：
   ```
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   ```
   然后 **Commit changes**
4. 仓库 → **Settings → Pages**
   - Source 选 **Deploy from a branch**
   - Branch 选 **main**，目录选 **/(root)** → **Save**
5. 等 1–2 分钟，页面顶部会出现网址：
   ```
   https://你的用户名.github.io/jiu-yi-jian/
   ```
6. 用手机打开这个网址，确认能用

> ⚠️ **仓库必须是 Public**（免费版不支持私有仓库开 Pages）。所以——
> **绝对不要把她的任何数据放进这个仓库。** 数据只在手机本地，永远不会出现在这些文件里。这一点在设计上就已经保证了。

> 📶 国内访问 GitHub Pages 有时会慢或断。如果她那边打不开，换 **Cloudflare Pages** 或 **Netlify**（拖拽上传，同样免费），或者用国内的 Gitee Pages（需实名）。

### 方案 B：Cloudflare Pages / Netlify

把整个文件夹拖到它们的网页上传区即可，不用 Git，通常几十秒出网址。步骤和上面第 5 步之后一样。

## 四、装到她手机上（Android）

1. 用 **Chrome** 打开那个 https 网址
2. 右上角 **⋮** → **添加到主屏幕** → 确认
3. 桌面出现橙色猫头图标，点开是**全屏**的，没有地址栏——和真 App 一样

装好之后**断网也能用**（Service Worker 已缓存）。

---

## 五、以后怎么更新

1. 改 `index.html`
2. 重新上传覆盖（GitHub 网页上直接 Upload 同名文件即可）
3. 她下次打开时**自动就是最新版**

页面用的是"网络优先"策略，所以改内容**不需要**改动 `sw.js` 里的版本号。
只有换了图标或 `manifest` 时，才需要把 `sw.js` 里的 `CACHE = "jiuyijian-v1"` 改成 `v2`。

## 六、数据与隐私

**数据存在哪**：她手机浏览器的 localStorage 里。换浏览器、清缓存、换手机都会丢。

**「使用摘要」是什么**：在「箱子」页点它，会生成一份统计，她可以选择复制并发给谁。

摘要里**只有次数和类别，一个字的任务内容都没有**：

```
「就一件」使用摘要
统计区间：2026-06-01 ~ 2026-06-07

打开 App            23 次
完成                9 件
有记录的日子         6 天
每天完成             2, 1, 3, 0, 2, 1

点「我卡住了」       7 次
  ├ 只做 2 分钟      5
  ├ 降低标准         1
  ├ 换一件           1
  └ 拆成小动作       0

看到拆解建议         6 次，采纳 4 次
走 AI 兜底           1 次
最常卡住的类别       沟通 3 ｜ 文书 2

—— 本摘要不含任何任务内容。
```

**永远不会自动上传。** 只能她手动点、手动复制、手动发出去。
这不是技术限制，是设计决定：**数据经过她，而不是绕过她。**

## 七、重新生成图标

```bash
node tools/make-icons.js
```

改颜色就编辑 `tools/make-icons.js` 里的 `BG`（背景）和 `BODY`（猫脸）两个色值。

## 八、设计红线（改代码时请守住）

这几条不是审美偏好，是这个工具能不能用的前提：

1. **永远不显示"还剩几件"**。那个数字对她就是债务。
2. **没有连续打卡，断了不清零**。因为根本没有连续记录可断。
3. **「换一件」不记账、不扣分、不记录次数**。失败在系统里不存在。
4. **小搭子不会因为她没做而难过**。没有死亡、生病、饥饿值，没有"你已经 N 天没来了"。
5. **主屏永远只有一件事**。不要加清单、不要加日历、不要加统计图表。
6. **AI 只能出现在「我卡住了」里**，而且必须有离线兜底。
7. **「今天就到这」和「再做一件」一样大**。能停下来和能开始一样重要。
